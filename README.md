## Результат

Небольшое PHP-приложение: список сотрудников из CSV, форма заявки (POST), серверная валидация, фильтрация таблицы по отделу (GET).

## Технологии

- PHP 8+
- HTML
- CSS

## Запуск

1. Установите PHP 8+ (проверка: `php -v`).
2. В корне проекта выполните:

```bash
php -S localhost:8000 -t public
```

3. Откройте в браузере: http://localhost:8000  
4. Остановка сервера: `Ctrl+C` в терминале.

Корень сайта — папка `public` (`-t public`), чтобы снаружи не отдавались `src/` и служебные файлы.

## Структура проекта

- `public/index.php` — точка входа (логика запроса + HTML)
- `public/style.css` — стили таблицы
- `src/functions.php` — `loadEmployees`, `validateApplication`, `filterEmployeesByDepartment`, `e`
- `data/` — рабочие копии данных
- `dataset/` — исходный dataset (`employees.csv`, `form_cases.json`)
- `README.md`
- `.gitignore`

## Dataset

- `employees.csv` — сотрудники (id, name, department, experience, email), разделитель `;`
- `form_cases.json` — тестовые сценарии валидации формы

## GET и POST

| | GET | POST |
|---|-----|------|
| Где данные | в URL (`?department=Разработка`) | в теле запроса |
| В PHP | `$_GET` | `$_POST` |
| В этой работе | фильтр таблицы по отделу | форма «Новая заявка» |
| Удобно | ссылку можно скопировать/обновить | данные заявки не светятся в адресе |

Фильтр: форма с `method="get"`.  
Заявка: форма с `method="post"`.

## htmlspecialchars (`e`)

Любое значение из CSV или от пользователя перед выводом в HTML проходит через `e()` → внутри `htmlspecialchars(..., ENT_QUOTES, 'UTF-8')`.

Так символы вроде `<`, `>`, `"` не становятся разметкой/скриптом в браузере (защита от XSS). Это про безопасный **вывод в HTML**, не про SQL.

## Путь данных: форма → ответ

1. Браузер отправляет форму (POST) или фильтр (GET).
2. PHP запускает `public/index.php` заново.
3. Подключается `src/functions.php`.
4. Из `data/employees.csv` читается список; при GET применяется фильтр по отделу.
5. Для POST: `trim` + `??`, затем `validateApplication` → массив `$errors` или успех.
6. Собирается HTML: таблица, сообщения об ошибках/успехе, поля формы с уже введёнными значениями (через `e()`).
7. Готовый HTML уходит в браузер.

## Как проверить

1. Главная: таблица из CSV, счётчик сотрудников.
2. Фильтр «Разработка» → в URL `?department=...`, в таблице только этот отдел; «Все» — снова все.
3. По сценариям `form_cases.json`:
   - пустое имя → ошибка;
   - опыт `-2` → ошибка;
   - корректные данные → «Заявка принята».
4. При ошибках поля формы сохраняют введённые значения.
